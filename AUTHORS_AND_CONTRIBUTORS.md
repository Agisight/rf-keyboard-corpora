# Authorship and Contributions

## Project Author

Ali Kuzhuget

RF Keyboard Corpora was initiated, designed, and coordinated by Ali Kuzhuget.

The overall project architecture, dataset structure, corpus integration methodology, keyboard framework, and long-press optimization approach were developed as part of the RF Keyboard Corpora project.

## Language Contributors

Many language profiles include contributions, reviews, corrections, and validation from native speakers, linguists, researchers, software developers, universities, language institutes, and language communities.

Language-specific metadata files may list individual contributors and reviewers for particular languages.

## Community Collaboration

The project follows a distributed contribution model where language expertise is provided by local experts while the overall technical framework remains shared across the dataset.

This approach enables scalable support for multiple Cyrillic languages while preserving language-specific knowledge and validation.
