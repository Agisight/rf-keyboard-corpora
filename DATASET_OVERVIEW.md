# RF Keyboard Corpora Overview

RF Keyboard Corpora is a corpus-based mobile keyboard infrastructure project designed to improve support for Cyrillic-based languages on modern devices.

## Key Statistics

- Languages: 53
- Language families: 8+ (Turkic, Slavic, Uralic, Mongolic, Northeast Caucasian, Northwest Caucasian, Iranian, Samoyedic and others)
- Speaker coverage: 138,875,887
- Total corpus size: 6.1 billion words
- Contributors: native speakers, linguists, researchers, software developers, universities, language institutes, and language communities

## Goals

- Mobile keyboard development
- Long-press optimization
- Language localization
- Predictive text systems
- Spell checking
- Educational software
- Language technology research
- AI and NLP applications

## Geographic Coverage

The dataset covers languages spoken across:

- Siberia
- North Asia
- Central Asia
- The Caucasus
- The Uralic region
- Northern Europe

## Project Vision

Modern written communication has largely moved from paper to digital devices.

RF Keyboard Corpora aims to provide reusable language infrastructure that enables speakers of Cyrillic-based languages to continue writing naturally in their native languages on modern mobile platforms and future AI systems.
