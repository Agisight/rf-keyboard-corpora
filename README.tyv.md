# rf-keyboard-corpora

> **Дылдар:** [English](README.md) · [Русский](README.ru.md) · **Тыва дыл**

**«РФ-клавиатура» төлевилелдиң корпус баазазы — бүгү кириллица дылдарынга системалыг раскладкалар.**

> **Төлевилелдиң сорулгалары**
>
> 1. **Орус системалыг раскладканы** калбартып, узун базыш (long-press) дузазы-биле Россия Федерациязының бүгү кириллица дылдарын хаара тудар.
> 2. РФ-тиң дыл бүрүзүнге **аңгы системалыг клавиатуралар** белеткээр.
> 3. Кандыг-даа шинчилекчиге эртем-билиг сорулгалар дээш.
> 4. Делегейниң бүгү кириллица дылдарын деткииринге төлевилелди белеткээр.

---

## 1. Кандыг медээ чыып турар бис болгаш чүге

| Кезек | Файл/папка | Сорулгазы |
| --- | --- | --- |
| **Монокорпус** | `raw/lang_mono_<N>.txt` | Сорулга дылда доктаамал текст; `N` — демдектер саны. **Демдектер аайы-биле** статистиканың кол дөзү (бир токен = бир Unicode демдек). |
| **Таваржылга** | `frequencies/lang_monocorpus_freq.csv` | «демдек → таварышканы» деп саблица — long-press хевирлерниң аайлаашкынынга салдарлыг. |
| **Раскладкалар** | `keyboard/lang_key_*.json` | Кол, 4-одуруглуг, нарын дээш о.ө. — белен iOS файлдар. |
| **Long-press маппинг** | `mapping/lang_key_mapping.json` | Дылдың немелде үжүктерин/демдектерин кайы **кол** орус үжүк адаанга көргүзерин айтыр. |
| **Чугаалакчылар статистиказы** | `stats/lang_population.csv` | «таваржылга × хаара тудуушкун» деп деңзилээр болгаш Apple мурнунга артыкшылдарны шынзыдар. Хаара тудуушкун = чугаалакчылар саны. |
| **Манифест** | `metadata.json` | Машина номчуй бээр метаданныг (версия, лицензия, харылзаа). |
| **README** | `README.md` | Кижи номчуй бээр тайылбыр: корпустуң дөзү, аштаашкын, онзагайлар. |

> `lang` — ISO 639-3 код (чижээ: `tyv`, `kbd`).

## 2. Силерниң үжүктериңерни орус дылдың үжүктеринге маппингтээри

Стандарт орус клавиатурада үжүктү узун базарга (амгы үеде Е → [Ё] дег), силерниң үжүктериңер эң чоок дөмей үжүк адаанга турар ужурлуг — калбарган «РФ-клавиатура» тургустунар болза, ол дамчыштыр көстүп кээр.

Силерниң үжүктериңерни орус үжүкке дүгжүрүн **lang_key_mapping.json** файлда:

```json
{
  "О": ["Ӧ", "Ө", "О̄"],
  "У": ["Ӱ", "Ү"],
  "Н": ["Ң"],
  "Е": ["Ё"]
}
```

азы **lang_key_mapping.txt** деп оожум хевирде:

```
О | Ӧ, Ө, О̄
У | Ӱ, Ү
Н | Ң
Е | Ё
```

*Ключ — кол орус клавиш; уткалары — таваржылга кызырлып бар чыдар аайы-биле хевирлер (ынчалза-даа бо ам ол хире чугула эвес).*

## 3. Вендорнуң бичии пайплайны (ам ажылдавайн турар)

1. **Корпус чыыңар** → `raw/`, бир демдек = бир токен.
2. **Таваржылгаларны санаңар** — Hugging Face-ке корпузуңарны чүдүрүп, [бо арында](https://github.com/Agisight/rf-keyboard-corpora/blob/rf/hf_freq_analyze.md) айыткал ёзугаар кылыңар; монокорпузуңарның медээзин санаар иштики механизм бар.
3. **`lang_key_mapping.txt` азы `lang_key_mapping.json`** файлды таарымчалыг редакторда холу-биле тургузуңар.
4. **Раскладкаларны белеткээр** (`keyboard/lang_key_default.json`, херек болза немелделер).
5. **Чугаалакчылар статистиказын немеңер**, `metadata.json` болгаш `README.md` долдуруңар.
6. **Pull-request ажыдыңар.**

## 4. Айтырыг-харыы (FAQ)

| Айтырыг | Харыы |
| --- | --- |
| **Бир дылга каш вендор турар аргалыг бе?** | Ийе. Аңгы `<vendor>` папкаларны ажыглаңар; скриптилер таваржылгаларны боду каттыштырар. |
| **Emoji, латиница болгаш өске чүве демдектерни канчаар боодаар?** | Таваржылга санаарда, скрипт кириллица Unicode блокче кирбес чүвени шупту кичээнгейге албас (default). Сорулга дылдың үжүктери артар, шимээн октаттынар. |
| **`lang_monocorpus_freq.csv`-ке дош болгаш бижик демдектерин киирер ужурлуг бе?** | Чок. Чүгле үжүк демдектерни болгаш дылдың онза демдектерин артырыңар; дош (пробел) болгаш бижик демдектерин киирбеңер. |
| **Корпусту чаартырда файлдарны канчаар адаар?** | Версия суффикс немеңер (`_v2`, хүн-ай) болгаш `metadata.json`-да `version` шөлүн чаартыңар. |
| **4-одуруглуг раскладка албан бе?** | Чок. Ажыктыг болза немеңер; кол портрет раскладка (3 одуруг демдек) албан. |
| **Корпуска кандыг лицензия шилиир?** | MIT азы дүүшкек ажык лицензия сүмелээр бис — Apple медээни хостуг ажыглап болзун дээш. |

---

**Корпус → Таваржылга → Эргономика** — тода медээ үжүктерниң турар черин объективтиг үндезинге тургузар. Корпустар болгаш статистика канчаар тода-дыр, Apple-га Россия Федерациязының бүгү кириллица дылдарын долузу-биле деткииринче кыйгырар аргумент ол хире шыырак болур.
